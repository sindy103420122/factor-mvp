# MVP 驗收清單（下週繳交）

## 範圍：小，但要能從頭跑到尾
- [ ] `requirements/`：至少 3 則 User Story（含 ID、3~5 條接受標準），可保留 US-101 並另寫至少 2 則
- [ ] `features/`：至少 3 個 Feature、6 個 Scenario，每個 Feature 含 1 個成功與 1 個邊界情境
- [ ] `docs/ADR-001_architecture.md`：寫明為何選此架構、為何不選其他
- [ ] `AGENTS.md` 與 `prompts/`：已放入，並依三支提示詞的順序使用
- [ ] `app/`：一行指令可跑出績效摘要
  - 至少 2 個因子（至少 2 個類別）
  - 規則式 baseline：依因子排名取前 N 檔，等權
  - 月調倉，扣除手續費與證交稅，報告換手率
  - 使用樣本內期間即可，股票池可以先縮小
- [ ] `behave` 全部通過（附上執行輸出）
- [ ] `ai_log/`：至少 3 筆，含 1 筆 AI 出錯與修正
- [ ] `README.md`：含 venv 建立、執行、測試指令

## MVP 不要求（完整版才做）
機器學習選股、樣本外驗收、5 個以上因子、報告簡報、五分鐘展示

- [ ] 每個因子都只用計算日當天已公布的資料
- [ ] 沒有隨機切分時間序列
- [ ] 根目錄沒有 Python 檔案
