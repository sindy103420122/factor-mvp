# User Story: 月調倉回測並扣除交易成本

## 基本資訊
- **ID**: US-104
- **版本**: Release_1
- **狀態**: In Progress
- **優先順序**: High

## User Story 描述

**作為** 基金經理人

**我想要** 看到策略每月調倉、扣除手續費、證交稅與滑價後的績效摘要與換手率

**以便於** 評估這個策略在真實交易成本下是否仍值得執行，並與加權報酬指數比較

## 接受標準

1. [ ] 每月最後一個交易日計算訊號，於下一個交易日收盤成交
2. [ ] 買進成本 = 成交金額 ×（手續費率 + 滑價率）；賣出成本 = 成交金額 ×（手續費率 + 證交稅率 + 滑價率）
3. [ ] 每期報告換手率 =（買進金額 + 賣出金額）÷ 2 ÷ 組合淨值
4. [ ] 成交日漲停的股票不得新買進，並記錄原因
5. [ ] 績效摘要至少包含：年化報酬、年化波動、Sharpe、最大回撤、平均月換手率、相對 benchmark 的年化超額報酬

## 相關資訊

**衝突**: 研究員希望高報酬，基金經理人希望低換手；本故事只負責「誠實呈現成本」，不負責降低換手。

**依賴**: US-101、US-102（因子）、US-103（股票池）

**備註**:
- baseline 選股規則：各因子每期做橫斷面 z-score，等權平均成綜合分數，取前 N 檔（預設 30）等權持有。
- 方向 2（智慧調權重）會在第 6～7 週替換「等權平均」這一步，其他步驟不變，因此本故事就是對照組。
- 樣本外期間（2023-01 起）預設鎖住，必須明確解鎖才能執行。
