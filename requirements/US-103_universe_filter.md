# User Story: 可交易股票池

## 基本資訊
- **ID**: US-103
- **版本**: Release_1
- **狀態**: In Progress
- **優先順序**: High

## User Story 描述

**作為** 量化研究員

**我想要** 在每個調倉日，只從「當時已上市櫃、且流動性足夠」的普通股中選股

**以便於** 回測結果是實際買得到、賣得掉的，並且不會因為只看存活下來的公司而高估績效

## 接受標準

1. [ ] 過去 60 個交易日平均成交金額低於門檻（預設 2,000 萬元）的股票，不得入選
2. [ ] 平均成交金額只使用調倉日當天以前的資料
3. [ ] 調倉日時已下市櫃的股票不得入選
4. [ ] 日後才下市櫃的股票，在下市前的調倉日仍可入選（不得因為「現在已下市」而被排除）
5. [ ] 調倉日時尚未上市櫃的股票不得入選

## 相關資訊

**衝突**: 與「小型股溢酬」有取捨：門檻越高越容易成交，但會排除小型股。門檻值需在報告中說明。

**依賴**: 需要每日成交金額，以及上市日、下市日資料

**備註**: 門檻 2,000 萬元為初始假設，可在樣本內做敏感度分析，但不得用樣本外結果調整。
