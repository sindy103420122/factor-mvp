# User Story: 12-1 個月價格動能因子

## 基本資訊
- **ID**: US-102
- **版本**: Release_1
- **狀態**: In Progress
- **優先順序**: High

## User Story 描述

**作為** 量化研究員

**我想要** 在任一計算日，取得每檔股票「過去 12 個月、但略過最近 1 個月」的還原股價報酬

**以便於** 把它當成動能因子，捕捉投資人對資訊反應不足的現象，同時避開短期反轉

## 接受標準

1. [ ] 動能 = 計算日前 1 個月的還原收盤價 ÷ 計算日前 12 個月的還原收盤價 − 1
2. [ ] 只使用計算日當天以前的價格，不使用計算日之後的任何價格
3. [ ] 「前 N 個月」取該日當天或之前最近一個有價格的交易日
4. [ ] 上市未滿 12 個月、缺少起點價格的股票，動能為缺值，不補 0
5. [ ] 使用還原股價（已調整除權息與減資），避免除息日被誤判為下跌

## 相關資訊

**衝突**: 無

**依賴**: 需要每日還原收盤價

**備註**: 選擇動能作為 MVP 第二個因子，是因為它只需要股價，沒有財報公布日的對齊問題；
與 US-101（成長類）分屬不同類別，符合 MVP「2 個因子、2 個類別」的要求。
