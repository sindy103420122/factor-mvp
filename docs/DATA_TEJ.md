# TEJ 資料準備說明

## 要從 TEJ 匯出哪些資料

| 檔名（放在 data/raw/） | 內容 | 期間 | 注意事項 |
|---|---|---|---|
| prices_raw.csv | 上市櫃普通股的**調整後**日收盤價、未調整收盤價、成交金額 | 2014-01 起 | 動能需要往前 12 個月，所以要比 2015-01 早一年 |
| revenue_raw.csv | 月營收，**含營收發布日** | 2013-01 起 | 年增率需要去年同月，所以要早兩年 |
| listing_raw.csv | 上市日、**下市日** | 全部 | 一定要包含已下市櫃公司，否則有存活者偏誤 |
| benchmark_raw.csv | 臺灣加權報酬指數（含息） | 2015-01 起 | 不是一般的加權指數，要選「報酬指數」 |

MVP 只需要前兩個檔案就能算因子；但要跑完整回測，四個都要。
股票池可以先縮小（例如只匯出上市公司或市值前 300 檔）來加快速度，在 README 說明即可。

## 轉檔步驟
1. 把匯出的檔案依上表命名，放進 `data/raw/`。
2. 打開 `app/tej_convert.py`，把 `COLUMN_MAP` 右邊改成你檔案實際的欄位名稱。
   轉檔時若欄位對不上，錯誤訊息會列出檔案實際有哪些欄位。
3. 確認金額單位（千元或元），必要時修改 `TRADE_VALUE_MULTIPLIER`。
4. 執行 `python -m app.tej_convert`，再執行 `python -m app.runner`。

## 三個常見陷阱
- **單位**：成交金額若是千元卻沒有乘 1000，流動性門檻會變成 200 億元，幾乎所有股票都被排除。
- **公布日**：若匯出的月營收沒有發布日欄位，轉檔會以「次月 10 日」替代，並印出替代筆數。
  替代比例很高時，請在報告說明，或回 TEJ 找有發布日的資料表。
- **授權**：`data/raw/` 與 `data/processed/` 都已列入 `.gitignore`，不要 commit 原始資料。
  若要讓助教重現，請在 README 寫清楚「匯出哪些資料表、哪些欄位、取得日期」。

## API 金鑰（若使用 tejapi 套件）
金鑰放在 `.env`，用環境變數讀取，絕對不要寫進程式或 commit。
