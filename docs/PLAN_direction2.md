# 專題方向 2：智慧調權重（草案）

## 一句話
保留既有因子不變，只讓「因子權重」依資料動態調整，檢驗它是否在扣成本後勝過固定權重。

## 對照組與智慧方法
| | 對照組（baseline） | 智慧方法 |
|---|---|---|
| 權重 | 5 因子等權（各 20%） | 依過去 36 個月 Rank IC 動態調整 |
| 程式位置 | `Settings.factor_weights` | 新增一個「每期回傳權重」的函式，傳給 `combine_scores` |
| 其他流程 | 完全相同 | 完全相同 |

## 智慧方法候選（由簡到繁，至少做第一個）
1. **IC 加權**：權重 ∝ 過去 36 個月平均 Rank IC；IC 為負的因子權重設為 0。
2. **IC 加權 + 收縮**：權重 = 0.5 × IC 加權 + 0.5 × 等權，降低雜訊（預期換手較低）。
3. **ICIR 加權**：用 IC 平均 ÷ IC 標準差，偏好穩定的因子。
4. **市場體制切換（加分）**：加權報酬指數低於 200 日均線時，提高低波動與品質因子權重。
   體制只能用當天以前的指數判斷。

## 關鍵的時點規則（之後寫成 Gherkin）
- 第 t 月的權重，只能用「到 t−1 月為止已實現」的 IC。
  因為第 t−1 月因子的 IC 要等到第 t 月底報酬實現後才知道。
- IC 的回看窗口從樣本內開始累積；樣本外期間權重仍逐月更新，但不得重新選擇窗口長度或收縮比例。

## 建議的完整版 5 個因子
| 類別 | 因子 | 經濟直覺 |
|---|---|---|
| 成長 | 月營收年增率（已完成） | 投資人對營收轉折反應不足 |
| 動能 | 12-1 個月報酬（已完成） | 行為偏誤造成趨勢延續 |
| 價值 | 股價淨值比（取倒數） | 風險補償，便宜的股票承擔較高風險 |
| 品質 | ROE（依財報公布日對齊） | 獲利能力高的公司被市場低估 |
| 低波動 | 60 日報酬標準差（取負號） | 投資人偏好樂透型股票，低波動股被低估 |

五個因子分屬五類，足以讓「調權重」有意義；若因子之間高度相關，調權重的效果會被稀釋，
所以第 4 週先畫相關係數矩陣。

## 時程對照
- 第 3 週：提案（本文件）
- 第 4 週：補齊 5 因子，完成等權 baseline，畫 IC 與相關矩陣
- 第 5～6 週：IC 加權與收縮版本，walk-forward 計算權重，扣成本比較
- 第 7 週：解鎖樣本外，只跑一次
