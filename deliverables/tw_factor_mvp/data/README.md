# 資料與建置狀態

`raw/` 保存 2015-01-01 至 2026-09-30 的公開來源快照：12 檔目前仍上市的大型股，以及 TWSE 加權報酬指數。股票涵蓋日價、財報、資產負債表、月營收、股利與除權息結果；個股清單及每份檔案的來源、行數與 SHA-256 見 `raw/manifest.json`。

`panel.csv` 是因子與月頻回測面板，`panel_qc.json` 記錄資料檢查摘要。個股除權息以 FinMind 除權息結果的前後參考價建立近似調整價格；基準指數取自 TWSE MFI94U。資料抓取與面板建置程序見 `../src/download_public_data.py`、`../src/build_panel.py`。

## 重要限制

這 12 檔是依目前市場認知選取的現存大型/流動股票，並非歷史每月點時股票池；回測存在存活者與選樣偏誤。財報 `date` 是財務期間而非公告時間；目前策略只用價格/市場因子，不以財報欄位產生交易訊號。調整價是根據除權息參考價的近似序列，並非供應商正式還原總報酬價格。結果僅為研究樣本，不是全市場、點時無偏績效，也不足以作為實盤依據。
